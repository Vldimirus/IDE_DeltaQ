# DeltaQ IDE - Детальная дорожная карта

## Общая структура

Разработка DeltaQ IDE разбита на **5 фаз**, каждая из которых добавляет функциональность поверх предыдущей. Каждая фаза завершается рабочей (хотя и неполной) версией IDE.
