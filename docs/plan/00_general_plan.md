# DeltaQ IDE - Общий план проекта

## Обзор

**DeltaQ IDE** -- интегрированная среда разработки, сочетающая традиционное текстовое программирование с визуальным блочным редактированием. Основная цель -- предоставить единую платформу для создания приложений на C/C++ с поддержкой визуального проектирования интерфейсов, модульной архитектуры и генерации кода.

### Ключевые принципы

- **Модульность**: все компоненты оформляются как модули (.dqmod), которые можно повторно использовать
- **Визуальное программирование**: графовый редактор для соединения модулей в программы
- **Генерация кода**: визуальные конструкции компилируются в чистый C/C++ код
- **Кроссплатформенность**: поддержка Windows, Linux, macOS

---

## Архитектура (обзор)

Система построена на **4-слойной архитектуре**:

| Слой | Назначение | Ключевые компоненты |
|------|-----------|---------------------|
| **Presentation** | Пользовательский интерфейс | Qt Widgets, QScintilla, Qt Graphics View |
| **Application** | Логика приложения | SessionManager, ActionManager, CommandBus, UndoManager |
| **Core Services** | Основные сервисы | ModuleRegistry, CodeGenerator, ProjectManager, BuildSystem |
| **Data** | Хранение данных | FileSystem, ModuleStore, GraphStore, UILayoutStore |

Все взаимодействие между слоями осуществляется через **CommandBus** -- шину команд, реализующую паттерн Command с поддержкой отмены/повтора (undo/redo).

## 4 основных модуля

### Модуль 1: Редактор кода (Code Editor)

Полнофункциональный текстовый редактор для C/C++.

- Интеграция с QScintilla для подсветки синтаксиса и автодополнения
- LSP-клиент (clangd) для интеллектуальных подсказок
- Система сборки: CMake + GCC/Clang/MSVC
- Поддержка аннотаций `@dqmodule` для определения модулей в коде
- Встроенный отладчик (GDB/LLDB)

### Модуль 2: Блочный редактор (Block Editor)

Визуальный редактор графов для соединения модулей.

- Реализация на Qt Graphics View Framework
- Узлы (nodes) и соединения (connections)
- Порты выполнения (execution) и данных (data)
- Компилятор графов: граф -> IR -> C/C++ код
- Визуальная отладка с подсветкой активных путей

### Модуль 3: Дизайнер интерфейсов (UI Designer)

Визуальный конструктор пользовательских интерфейсов.

- Drag&Drop размещение виджетов
- Редактор свойств
- Система компоновки (layouts)
- Генерация кода на SDL2
- Привязка событий к обработчикам

### Модуль 4: Обработчик библиотек (Library Processor)

Инструмент для импорта существующих C/C++ библиотек.

- Парсинг AST через libclang
- Декомпозиция функций и классов в .dqmod модули
- Генерация обёрточного (wrapper) кода
- Обработка C++ классов, шаблонов и пространств имён

## Форматы файлов

### Проект (.dqproj)

JSON-файл описания проекта, содержащий ссылки на модули, графы, UI-макеты и настройки сборки.

```json
{
  "name": "MyProject",
  "version": "1.0.0",
  "modules": ["modules/*.dqmod"],
  "graphs": ["graphs/*.dqgraph"],
  "ui_layouts": ["ui/*.dqui"],
  "build": {
    "compiler": "gcc",
    "standard": "c17",
    "output": "build/"
  }
}
```

### Модуль (.dqmod)

JSON-файл описания модуля с портами ввода/вывода.

```json
{
  "id": "uuid",
  "name": "add",
  "version": "1.0.0",
  "language": "c",
  "description": "Adds two integers",
  "ports": {
    "input": [{"name": "a", "type": "int"}, {"name": "b", "type": "int"}],
    "output": [{"name": "result", "type": "int"}]
  },
  "source": "modules/math/add.c",
  "header": "modules/math/add.h",
  "dependencies": []
}
```

### Граф (.dqgraph)

JSON-файл описания визуального графа -- узлы и соединения.

```json
{
  "id": "uuid",
  "name": "main_graph",
  "nodes": [
    {"id": "n1", "module_id": "add-uuid", "position": {"x": 100, "y": 200}}
  ],
  "connections": [
    {"from": {"node": "n1", "port": "result"}, "to": {"node": "n2", "port": "value"}}
  ]
}
```

### UI-макет (.dqui)

JSON-файл описания интерфейса -- виджеты, свойства, привязки событий.

## Зависимости

| Зависимость | Версия | Назначение |
|-------------|--------|-----------|
| **Qt 6** | >= 6.5 | Фреймворк UI, Graphics View |
| **QScintilla** | >= 2.14 | Редактор кода |
| **clangd** | >= 16 | LSP-сервер для C/C++ |
| **libclang** | >= 16 | Парсинг AST C/C++ |
| **CMake** | >= 3.24 | Система сборки |
| **SDL2** | >= 2.28 | Целевая платформа для генерируемого UI |
| **GCC/Clang/MSVC** | -- | Компиляторы |
| **GDB/LLDB** | -- | Отладчики |
| **nlohmann/json** | >= 3.11 | Работа с JSON |
