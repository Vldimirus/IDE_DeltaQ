# Core Math Modules

## Роль категории

`math` в `core` покрывает два слоя:

- минимальную целочисленную арифметику для базовых графов;
- небольшой прикладной хвост для частых задач, который уже не входит в baseline.

То есть это не математическая библиотека общего назначения, а стартовый набор
арифметики для модульной композиции.

## Essential

### `core.math.add`

- Роль: `essential`
- Зачем нужен: базовое сложение `int`
- Когда брать: для любых простых числовых расчётов в data-flow

### `core.math.subtract`

- Роль: `essential`
- Зачем нужен: базовое вычитание `int`
- Когда брать: когда нужно получить разницу двух значений

### `core.math.multiply`

- Роль: `essential`
- Зачем нужен: базовое умножение `int`
- Когда брать: для коэффициентов, масштабирования и счётных расчётов

### `core.math.divide`

- Роль: `essential`
- Зачем нужен: базовое целочисленное деление
- Когда брать: если в графе осознанно используется `int`-деление
- Ограничение: при делении на ноль возвращает `0`, без отдельной ошибки

## Legacy

### `core.math.abs`

- Роль: `legacy`
- Почему выведен из рекомендуемого baseline:
  - это узкий прикладной `int`-helper
  - такой модуль лучше живёт во внешнем numeric pack-е или как локальный helper проекта
- Когда брать: только для совместимости со старыми графами

## Практическое правило

Для `math` особенно важно не засорять `core`:

- `essential` — только то, без чего базовый числовой граф неудобно собрать;
- `specialized` — полезные helpers, но не повод превращать `core` в замену `libm` или прикладной numeric pack;
- `legacy` — старые thin wrapper-ы и partial float helper-ы, которые больше не считаются хорошим baseline-решением;
- всё остальное лучше уводить во внешние packs или предметные библиотеки.
