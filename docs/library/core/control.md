# Core Control Modules

## Роль категории

`control` в `core` отвечает за минимальную модель управления потоком:

- ветвление;
- последовательное выполнение;
- простой счётный цикл.

Это фундамент для `exec`-графов DeltaQ. Всё, что выходит за этот минимум,
должно очень аккуратно попадать в `core`.

## Essential

### `core.control.if_branch`

- Роль: `essential`
- Зачем нужен: основное ветвление `exec`-потока по `bool`
- Когда брать: если нужно реально разделить выполнение на `true/false`

### `core.control.sequence`

- Роль: `essential`
- Зачем нужен: последовательное продолжение `exec`-цепочки по нескольким выходам
- Когда брать: когда один шаг должен запустить несколько следующих шагов по очереди

### `core.control.for_loop`

- Роль: `essential`
- Зачем нужен: базовый счётный цикл для повторения body фиксированное число раз
- Когда брать: если достаточно простой модели `count + index`

## Legacy

### `core.control.if_then`

- Роль: `legacy`
- Что делает: выбирает одно `int`-значение по условию
- Почему выведен из рекомендуемого baseline:
  - это не управление `exec`-потоком
  - это узкий data-flow helper только для `int`
  - такой helper лучше выглядит как локальный submodule или внешний extension pack
- Когда брать: только если нужна совместимость со старыми графами или уже принят именно этот короткий `int`-тернарный паттерн

### `core.control.delay_ms`

- Роль: `legacy`
- Что делает: блокирующая пауза в миллисекундах
- Почему выведен из рекомендуемого baseline:
  - это runtime helper, а не базовая модель управления графом
  - он навязывает блокирующий паттерн там, где чаще нужен event-loop или внешний таймерный слой
  - по смыслу лучше живёт во внешнем runtime/extension pack-е
- Когда брать: только если нужна совместимость со старыми графами или очень простой demo/polling сценарий

## Практическое правило

Для нового `control`-модуля сначала нужно ответить на вопрос:

- это реально часть минимальной модели потока;
- или это уже специальный helper для частного runtime-сценария.

Если модуль не усиливает саму модель `exec`-графа, а лишь сокращает частный
паттерн, его место скорее в `specialized`, `legacy` или вообще вне `core`.
