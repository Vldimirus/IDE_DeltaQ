# Core IO Modules

## Роль категории

`io` в `core` закрывает минимальный console-baseline DeltaQ:

- вывод текста;
- чтение строки;
- простые константы для запуска графа без внешнего источника данных.

Это не универсальная I/O-подсистема, а именно стартовый набор для
`console`-workflow и быстрых эталонных сценариев.

## Essential

### `core.io.print`

- Роль: `essential`
- Зачем нужен: базовый вывод строки без перевода строки
- Когда брать: если строка уже собрана и нужно просто вывести её в stdout

### `core.io.println`

- Роль: `essential`
- Зачем нужен: базовый вывод строки с переводом строки
- Когда брать: если нужен нормальный console output по строкам

### `core.io.read_line`

- Роль: `essential`
- Зачем нужен: интерактивный ввод строки пользователем
- Когда брать: для console input сценариев и эталонных demo-потоков

### `core.io.int_constant`

- Роль: `essential`
- Зачем нужен: подача фиксированного `int` в граф
- Когда брать: если значение задаётся вручную как свойство узла

### `core.io.string_constant`

- Роль: `essential`
- Зачем нужен: подача фиксированной строки в граф
- Когда брать: для литералов, prompt-ов, заголовков и тестовых значений

## Legacy

### `core.io.print_float`

- Роль: `legacy`
- Почему выведен из рекомендуемого baseline:
  - это узкий typed-output shortcut
  - он раздувает `core`, не образуя целостного float baseline
- Когда брать: только для совместимости со старыми графами
- Ограничение: формат вывода фиксирован и не настраивается

## Legacy

### `core.io.print_int`

- Роль: `legacy`
- Почему выведен из baseline:
  - дублирует composable-путь `int_to_string + print/println`
  - стимулирует разрастание `core` множеством typed-output shortcut-ов
- Что делать вместо него:
  - использовать `core.conversion.int_to_string`
  - затем `core.io.print` или `core.io.println`

## Практическое правило

Если задача укладывается в:

- `text -> print/println`
- `read_line -> conversion -> logic/control`

то `core.io` используется правильно.

Если хочется добавить новый модуль вида `print_<type>`, сначала нужно доказать,
что эта задача не решается уже существующей composable-связкой.
