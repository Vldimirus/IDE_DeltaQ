# DeltaQ IDE — Правила проекта

## Язык общения

- Все диалоги ведутся на **русском языке**
- Комментарии в исходном коде — на **русском языке**
- Документация (MD-файлы) — на **русском языке**

## Структура каталогов

Каждая папка — под свои задачи. Файлы не должны быть перемешаны.

```
IDE_DeltaQ/
├── CLAUDE.md           ← Этот файл (правила проекта)
├── CMakeLists.txt      ← Корневой файл сборки
├── docs/               ← Вся документация (MD-файлы, планы, прогресс)
│   ├── PROGRESS.md     ← Прогресс разработки (обновляется автоматически)
│   └── plan/           ← Детальные планы (00–09)
├── src/                ← Все исходники (код проекта)
│   ├── core/           ← Ядро IDE (MainWindow, CommandBus, Registry...)
│   ├── editor/         ← Модуль 1: Редактор кода
│   ├── blockEditor/    ← Модуль 2: Визуальный блочный редактор
│   ├── uiDesigner/     ← Модуль 3: Дизайнер UI
│   ├── libProcessor/   ← Модуль 4: Обработчик библиотек
│   ├── codegen/        ← Генерация кода и языковые бэкенды
│   ├── lsp/            ← LSP-клиент
│   ├── debug/          ← Отладчик
│   └── platform/       ← Платформенная абстракция
├── include/            ← Публичные заголовочные файлы (.h)
├── build/              ← Сборка проекта (не коммитится в git)
├── scripts/            ← Скрипты сборки и автоматизации
├── tests/              ← Тесты
├── resources/          ← Ресурсы (иконки, темы, шаблоны)
└── third_party/        ← Сторонние библиотеки
```

### Правила размещения файлов

- **Документация** (.md) — только в `docs/`
- **Исходный код** (.cpp, .h) — только в `src/` и `include/`
- **Скрипты** (.sh, .py) — только в `scripts/`
- **Тесты** — только в `tests/`
- **Сборка** — только в `build/` (не добавлять в git)
- Не создавать файлы в корне проекта без необходимости

## Прогресс разработки

**После выполнения каждого этапа — автоматически обновлять `docs/PROGRESS.md`:**

- Отметить выполненный этап в разделе "Выполненное" с датой и описанием
- Обновить прогресс-бары в разделе "Общий прогресс"
- Обновить раздел "Текущие задачи"
- Обновить дату "Последнее обновление"

## Стек технологий

- **IDE:** Qt 6 + C++20 + CMake
- **GUI генерируемого кода:** SDL2
- **Редактор кода:** QScintilla
- **Парсинг C/C++:** libclang
- **Архитектура:** 4-слойная модель с CommandBus (см. `docs/plan/01_architecture.md`)
- **Мультиязычность:** IR → LanguageBackend (C первый, Python/Rust в будущем)
